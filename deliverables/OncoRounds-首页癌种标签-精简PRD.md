# OncoRounds 首页癌种标签 PRD

## 1. 需求说明

将首页原有“今日推荐病例”区域标题替换为可点击的癌种标签，帮助肿瘤科医生按癌种查找对应病例。本次仅说明标签展示及其筛选行为。

## 2. 页面调整

在原“今日推荐病例”所在位置展示一排癌种标签，移除原标题及其前方红点。标签下方沿用现有病例卡片区域。

标签固定按以下顺序展示：

| 顺序 | 标签名称 | 标签 ID |
|---|---|---|
| 1 | 肺癌 | lung |
| 2 | 胃癌 | gastric |
| 3 | 乳腺癌 | breast |
| 4 | 食管癌 | esophageal |
| 5 | GEJ腺癌 | gej |

沿用现有蓝紫色视觉风格，选中标签与未选中标签需有明确区分。标签文字完整展示、不换行；窄屏时标签区域可横向滑动，页面本身不得横向溢出。桌面端仍在居中的手机画布内展示。

## 3. 交互规则

首次进入首页时，默认选中“肺癌”，下方展示肺癌病例。

点击其他癌种标签后，将该标签设为唯一选中项，下方更新为对应癌种的病例卡片，并默认选中该癌种第一例；筛选在当前首页完成。

重复点击当前已选中的标签时，保持当前病例位置。

从病例详情、答题或总结返回首页时，保留离开前选中的癌种和病例。

“胃食管结合部腺癌”归入“GEJ腺癌”标签，病例正文中的疾病名称保持原文。

## 4. 验收标准

| 检查项 | 预期结果 |
|---|---|
| 替换位置 | 原“今日推荐病例”标题及红点不再展示，同位置显示癌种标签 |
| 标签内容 | 共五个标签，名称与顺序和上表一致 |
| 默认状态 | 首次进入默认选中肺癌，下方展示肺癌病例 |
| 点击筛选 | 点击任一其他标签，仅展示对应癌种病例，默认选中第一例 |
| 单选状态 | 任意时刻仅有一个癌种标签处于选中状态 |
| 重复点击 | 再次点击当前标签，不重置当前病例位置 |
| 返回保留 | 从详情、答题或总结返回首页，癌种和病例位置保持一致 |
| 窄屏展示 | 标签可横向滑动，文字不截断、不换行，页面无横向溢出 |
| GEJ归类 | 胃食管结合部腺癌病例显示在GEJ腺癌标签下，正文名称不变 |

## 5. 埋点需求

用于了解各癌种标签的曝光、点击及点击用户率。事件标识和属性变量名均使用英文、数字和下划线，不以数字或 `$` 开头；相同属性在不同事件中保持相同含义与数据类型。

### 5.1 事件定义

| 事件显示名 | 事件标识 | 触发时机 | 去重规则 |
|---|---|---|---|
| 癌种标签曝光 | `cancer_tag_view` | 标签在首页标签容器中的可见面积达到 50% 时触发，包括首次进入首页已可见的标签，以及横向滑动后新进入可视区域的标签 | 同一首页页面实例内，同一 `cancer_tag_id` 最多上报一次 |
| 癌种标签点击 | `cancer_tag_click` | 用户主动点击任一癌种标签时触发；重复点击当前已选中标签也触发 | 一次有效点击手势上报一次，不做跨点击去重 |

“同一首页页面实例”指从首页页面创建至离开或销毁的本次生命周期。仅切换标签、横向滑动或前后台切换但页面实例未销毁时，不重新计算；页面刷新或离开后再次进入并创建新页面实例时，可重新上报曝光。

默认选中“肺癌”属于页面初始化行为，只记录曝光，不记录点击。从病例详情、答题或总结返回首页时，自动恢复之前选中的癌种，不记录点击；如首页页面实例已重新创建，则按当前实际可见状态重新记录曝光。

### 5.2 事件属性

| 属性显示名 | 属性变量名 | 数据类型 | 是否必传 | 适用事件 | 属性值或说明 |
|---|---|---|---|---|---|
| 癌种标签 ID | `cancer_tag_id` | STRING | 是 | 曝光、点击 | `lung`、`gastric`、`breast`、`esophageal`、`gej` |
| 癌种标签名称 | `cancer_tag_name` | STRING | 是 | 曝光、点击 | 肺癌、胃癌、乳腺癌、食管癌、GEJ腺癌；必须与标签 ID 映射一致 |
| 癌种标签位置 | `cancer_tag_position` | NUMBER | 是 | 曝光、点击 | 固定为 1～5 的整数，必须与标签配置顺序一致 |
| 曝光时是否选中 | `is_selected` | BOOL | 是 | 曝光 | `true`：曝光时已选中；`false`：曝光时未选中 |
| 点击前选中的标签 ID | `previous_cancer_tag_id` | STRING | 是 | 点击 | 取点击处理、选中状态更新之前的标签 ID；枚举与 `cancer_tag_id` 相同 |
| 是否发生癌种切换 | `is_switched` | BOOL | 是 | 点击 | 点击标签 ID 与点击前选中标签 ID 不同时为 `true`，相同时为 `false` |

属性固定映射如下：

| 标签 ID | 标签名称 | 标签位置 |
|---|---|---|
| `lung` | 肺癌 | 1 |
| `gastric` | 胃癌 | 2 |
| `breast` | 乳腺癌 | 3 |
| `esophageal` | 食管癌 | 4 |
| `gej` | GEJ腺癌 | 5 |

事件应沿用项目现有神策 SDK 的登录用户身份关联和公共属性配置，包括已有的平台、版本等公共属性；不得另建同义属性。用户数统一使用项目默认分析主体统计，不额外上报自定义 `user_id` 属性。

### 5.3 统计口径

| 指标 | 计算方式 |
|---|---|
| 标签曝光次数 | `cancer_tag_view` 事件总次数，按 `cancer_tag_id` 分组 |
| 标签曝光用户数 | `cancer_tag_view` 事件用户数，按 `cancer_tag_id` 分组 |
| 标签点击次数 | `cancer_tag_click` 事件总次数，按 `cancer_tag_id` 分组 |
| 标签点击用户数 | `cancer_tag_click` 事件用户数，按 `cancer_tag_id` 分组 |
| 标签点击用户率 | 标签点击用户数 ÷ 标签曝光用户数 × 100% |
| 标签切换点击次数 | `cancer_tag_click` 事件总次数，筛选 `is_switched = true` |

标签点击用户率的分子和分母必须使用相同统计周期、相同分析主体，并按同一 `cancer_tag_id` 对应计算。该指标为用户口径，不称为“点击次数率”或标准 PV CTR。

### 5.4 埋点验收

- 首次进入首页时，实际可见的标签分别产生一次曝光事件；肺癌的 `is_selected = true`，其余已曝光标签为 `false`，且默认选中行为不产生点击事件。
- 同一首页页面实例内反复横向滑动，使同一标签多次进出可视区域，该标签仍只产生一次曝光事件；新进入可视区域的标签产生一次曝光事件。
- 依次点击五个癌种标签，每次点击均产生一条 `cancer_tag_click`，标签 ID、名称、位置及数据类型符合属性表和固定映射。
- 同一标签连续点击两次，产生两条点击事件；两条事件均满足 `is_switched = false`，且每次点击手势只上报一次。
- 点击其他标签时，`previous_cancer_tag_id` 等于状态更新前的标签 ID，`is_switched = true`；更新后的 `cancer_tag_id` 不得与 `previous_cancer_tag_id` 相同。
- 从详情、答题或总结返回首页并自动恢复标签时，不产生点击事件；若创建了新的首页页面实例，则按实际可见标签重新产生曝光事件。
- 使用项目默认分析主体查询时，可分别按 `cancer_tag_id` 统计曝光次数、曝光用户数、点击次数、点击用户数和标签点击用户率。
- 在相同统计周期和相同标签 ID 下，点击用户数原则上不得大于曝光用户数；如出现异常，需检查曝光触发、用户身份关联和事件漏报。
