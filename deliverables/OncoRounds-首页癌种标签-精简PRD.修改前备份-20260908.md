# OncoRounds 首页癌种标签 PRD

## 1. 需求说明

将首页原有“今日推荐病例”区域标题替换为可点击的癌种标签，帮助肿瘤科医生按癌种查找对应病例。本次仅说明标签展示及其筛选行为。

## 2. 页面调整

在原“今日推荐病例”所在位置展示一排癌种标签，移除原标题及其前方红点。标签下方沿用现有病例卡片区域。

标签固定按以下顺序展示：

| 顺序 | 标签名称 | 标签 ID |
|---|---|---|
| 1 | 肺癌 | lung |
| 2 | 胃癌 | gastric |
| 3 | 乳腺癌 | breast |
| 4 | 食管癌 | esophageal |
| 5 | GEJ腺癌 | gej |

沿用现有蓝紫色视觉风格，选中标签与未选中标签需有明确区分。标签文字完整展示、不换行；窄屏时标签区域可横向滑动，页面本身不得横向溢出。桌面端仍在居中的手机画布内展示。

## 3. 交互规则

首次进入首页时，默认选中“肺癌”，下方展示肺癌病例。

点击其他癌种标签后，将该标签设为唯一选中项，下方更新为对应癌种的病例卡片，并默认选中该癌种第一例；筛选在当前首页完成。

重复点击当前已选中的标签时，保持当前病例位置。

从病例详情、答题或总结返回首页时，保留离开前选中的癌种和病例。

“胃食管结合部腺癌”归入“GEJ腺癌”标签，病例正文中的疾病名称保持原文。

## 4. 验收标准

| 检查项 | 预期结果 |
|---|---|
| 替换位置 | 原“今日推荐病例”标题及红点不再展示，同位置显示癌种标签 |
| 标签内容 | 共五个标签，名称与顺序和上表一致 |
| 默认状态 | 首次进入默认选中肺癌，下方展示肺癌病例 |
| 点击筛选 | 点击任一其他标签，仅展示对应癌种病例，默认选中第一例 |
| 单选状态 | 任意时刻仅有一个癌种标签处于选中状态 |
| 重复点击 | 再次点击当前标签，不重置当前病例位置 |
| 返回保留 | 从详情、答题或总结返回首页，癌种和病例位置保持一致 |
| 窄屏展示 | 标签可横向滑动，文字不截断、不换行，页面无横向溢出 |
| GEJ归类 | 胃食管结合部腺癌病例显示在GEJ腺癌标签下，正文名称不变 |

## 5. 埋点需求

用于了解癌种标签的展示和点击情况。

| 事件名称 | 事件标识 | 触发时机 | 记录参数 |
|---|---|---|---|
| 癌种标签曝光 | `cancer_tag_view` | 标签实际进入可视区域时触发；每次进入首页，同一标签仅记录一次 | 标签 ID、标签名称、标签位置、是否选中 |
| 癌种标签点击 | `cancer_tag_click` | 用户点击标签时触发，重复点击当前标签也记录 | 标签 ID、标签名称、标签位置、点击前选中的标签 ID、是否发生切换 |

### 各癌种点击埋点明细

五个癌种均需接入点击埋点。每次点击任一癌种标签时，上报一次 `cancer_tag_click`，通过标签 ID 区分癌种，分别统计各癌种的点击次数、点击用户数及点击率。重复点击当前已选中的标签也必须上报。

| 点击对象 | 事件标识 | 标签 ID | 标签名称 | 标签位置 |
|---|---|---|---|---|
| 肺癌标签 | `cancer_tag_click` | `lung` | 肺癌 | 1 |
| 胃癌标签 | `cancer_tag_click` | `gastric` | 胃癌 | 2 |
| 乳腺癌标签 | `cancer_tag_click` | `breast` | 乳腺癌 | 3 |
| 食管癌标签 | `cancer_tag_click` | `esophageal` | 食管癌 | 4 |
| GEJ腺癌标签 | `cancer_tag_click` | `gej` | GEJ腺癌 | 5 |

每条点击事件还需记录点击前选中的标签 ID，以及本次点击是否发生癌种切换。

### 统计口径

- 默认选中“肺癌”只记录曝光，不记录点击。
- 横向滑动后新进入可视区域的标签记录曝光，滑动本身不记录点击。
- 标签位置按固定顺序记录为 1～5，与标签配置表一致。
- 自动恢复之前选中的癌种，不记录点击。
- 标签点击率＝该标签点击用户数 ÷ 该标签曝光用户数，按同一统计周期去重。

### 埋点验收

- 依次点击五个癌种标签，每个癌种均产生对应的点击事件，标签 ID、名称及位置与上表一致。
- 同一标签连续点击两次，记录两次点击；每次点击仅上报一次事件。
- 点击当前已选中标签时，“是否发生切换”为否；点击其他标签时为是。
- 五个癌种的点击次数、点击用户数及点击率可分别统计。
