# 答题中病例回看与解析可读性设计

## 目标

在不重置答题进度的前提下，让用户在答题页随时查看病例摘要和病程轴；同时把肺癌疗效影像放到病例摘要，并提升解析依据的可读性。

## 交互设计

- 肺癌病例的“疗效影像评估”卡片从病程轴底部移动到病例摘要底部，卡片内容与图片保持不变。
- 答题页右上角增加“病例资料”按钮，取代仅作状态提示的绿色圆点位置。
- 点击“病例资料”后打开覆盖当前答题页的资料层，默认显示“病例摘要”，并提供“病例摘要 / 病程轴”两个 Tab。
- 资料层顶部提供“返回答题”按钮。关闭资料层后回到原问题，当前题号、已选答案、已提交状态和历史答案全部保留。
- 资料层只展示病例内容，不允许从其中重新开始查房或切换病例。

## 实现方式

延续现有 `assets/lung-treatment-response.js` 的渐进增强方式：在病例详情页出现时缓存当前病例的摘要和病程轴 DOM，在开始答题前补齐未访问的 Tab 内容；答题页出现时注入“病例资料”入口和覆盖层。这样无需改写压缩后的 React 主包，也不会改变现有答题状态机。

肺癌疗效影像卡片改为插入 `.summary-list`。覆盖层复用缓存的病例节点，避免维护第二份病例数据。样式集中在 `assets/lung-treatment-response.css`，并将 `.evidence-line` 字号从 9px 提升到 11px，行高同步调整为 1.55。

## 状态与异常处理

- 缓存以病例标题区分，避免三个病例之间内容串用。
- 若资料缓存尚未完成，“病例资料”入口保持不可用；缓存完成后自动启用。
- 打开资料层时锁定背景滚动，关闭后恢复。
- 按 Escape、点击“返回答题”均可关闭资料层；焦点返回触发按钮。

## 验收标准

1. 肺癌疗效影像只出现在病例摘要，不再出现在病程轴。
2. 答题任一阶段都能打开病例资料，并在摘要与病程轴之间切换。
3. 关闭病例资料后题号、选择和提交状态保持不变。
4. 解析中的“依据”计算字号为 11px。
5. iPhone 常规尺寸下覆盖层无横向溢出，入口、Tab 和关闭按钮可触达。
6. 页面无新增控制台错误或警告。
