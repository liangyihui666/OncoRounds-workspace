# 三病例综合修复 v2

本版在“选项均衡版”上继续修复，沿用现有大查房工作流合同，没有重建流程、增加调用轮次或改动子应用ID。

## 导入顺序

1. 用 `题目生成-三病例综合修复-v2-20260904.json` 更新目前供三连调用的“题目生成”应用，保存并发布。
2. 用 `三连-证据原文终选与回退追踪-v2-20260904.json` 更新“三连”应用。
3. 如果导入成了一个全新的题目生成应用，三连中的“题目生成”“题目生成#2”“题目生成#3”须重新选择这个新应用。若在原应用中更新，三处原引用保持不变。

新一轮结果的最终传输包、候选池和终选报告均带有 `workflow_revision: 20260904-followup-v2`，便于确认实际运行的是新版。

## 保持不变

- 首轮仅真实审核PASS且至少75分通过；第二轮保留原有候选直出/首轮回退规则，同时如实显示医学REVISE与风险。
- 三连有至少5道结构完整候选时仍选5道；答案字母、字数或来源分布不会单独导致0题。
- 只有title/disease必填，不恢复人工确认或资料补充节点。
- 首轮生成temperature=0.3，修订=0.2，校验=0.1，终选=0.2。
- 保留上一版选项长度、句式、动作数和干扰项可信度约束。未机械截断、补长或改写已生成选项。
- 两个文件分别仍为48节点/62连线和14节点/14连线；BOM、根结构、既有输出字段和子应用引用保持。
