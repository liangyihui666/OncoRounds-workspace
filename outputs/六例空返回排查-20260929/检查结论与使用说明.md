# 六例空返回排查

本次实际收到6份“json生成”节点输入。用户补充错误为 `Invalid worker response`。

结论：存在两个独立问题——沙箱执行/回传失败，以及题目本身未通过检查。不能把空返回全部解释成知识库不足，也不能为了消除空返回放行失败题。

## 已做的工作流修改

文件：`02-HTML单例外层-精简返回版.json`。基于已交付的“证据原句核对与进阶出题”配套外层，只改“json生成”一个节点。

- 返回对象只保留下游实际使用的 `response_json`，删除重复输出别名。完整题目、病例详情、执行报告、原句检查及失败草稿仍在这份JSON内。
- 保留成功5题及失败0题的原有规则；不修改题目内容，不删除证据核对，不把FORMAT_ERROR改为成功。
- 子应用、知识库/ALK补充链、Flash模型、两轮调用、批量并发及全部连线均未修改。
- 没有缩短或删除证据正文，也没有对符号、否定或数字做自动修正。

六份实际输入离线重放，返回体由225,297–352,140字节降至50,524–87,254字节，减少75.0%–77.6%。原 `response_json` 字符串逐字不变。14项离线检查通过，**未在线验证，不能据此声称worker错误已解决**。

## 现在只操作这一步

1. 节点：HTML单例外层的 **json生成**。
2. 字段：**JavaScript代码**。
3. 动作：用同目录 `json生成-替换代码.js` 全文替换并保存。原有 `response_json` 输出保留；仅粘代码时其他旧输出可以暂留，本次返回已不再填充它们。
4. 预期：用 **CASE-794E8394 胃癌CAPOX** 原输入做节点调试，`response_json` 非空，解析后题量为5。该测试只检验程序回传，不代表题目合格。
5. 回传：该节点实际输出或新的完整错误提示。不需要重跑检索及两轮AI。

也可用完整外层JSON更新已有外层应用，但不要新建应用导致原有批量应用调用ID变化。子应用和批量文件本轮不用替换。

## 对worker错误的证据范围

FastGPT官方实现的 `BaseProcessPool.sendTask()` 在解析worker行响应及后续同步处理出现异常时返回此错误；它并不等价于“模型JSON错误”，也不专指“内存不足”或“返回体超限”。官方代码提供workerId、responseLength、异常堆栈和stderr用于区分原因。

- [官方响应处理代码](https://github.com/labring/FastGPT/blob/main/projects/code-sandbox/src/pool/base-process-pool.ts)
- [官方增加错误日志的修改](https://github.com/labring/FastGPT/pull/7689)
- [4.17.0说明](https://doc.fastgpt.io/en/self-host/upgrading/4-17/4170)

本地Node重放六例均成功，未复现该平台错误。冗余返回体是已确认的问题；它是否触发了线上错误目前仍属待验证假设。如果同一输入精简后仍报错，应查看code-sandbox的上述日志字段，不能继续靠加长出题提示词排查。

## 内容问题：即使程序通过也不能直接入库

以下仅核对本次提供的病例与绑定证据，不是新增临床治疗建议，也未独立验证知识库源文正确性。

### CAPOX胃癌

- **Q2、Q5**：病例未记载毒性等级。Q2解释写“本例采取减量提示更高级别”，Q5引用III度规则证明本例终止合理，均把处置反推成未记录的等级/风险结论。绑定正文实际上区分I至IV度，不能删去这一区分。
- **Q3**：决定当时是否二线治疗时，使用“后续自行缩小”排除进展，混入未来信息；来源的二线适用条件也不是一份完整的疗效评价标准。
- **Q4**：证据是治疗前确诊与分期原则，题目却推成“影像学CR必须内镜病理确认”，又用个案三年后活检来证明确认时限无要求。结论范围超出绑定记录。
- **Q1**：2016年时点使用2026年方案，未明确当前证据回顾。CPS与TAP也应分别保留，不能将一种评分当另一种检测结果。

### HER2阳性/MSI-H胃癌

- **Q3**：绑定片段来自淋巴瘤指南，含“中性粒细胞计数小于0.5×10⁹/L时暂停”的明确阈值。题干明确分级未记载，却在解析中泛化为无条件暂停规则；且片段不足以识别责任药适用范围。结论看似合理不等于本条证据支持完整处置。
- **Q5**：“pCR可能主要归因于抗HER2组分”“曲妥珠单抗贡献大”未由所绑定的MSI-H标志物段落证明；单例联合治疗不能分离各组分贡献。
- **Q1**：解析把另一分层的“同步放化疗”称为Level I；本次返回的表格把该项列在II级列，I级为系统治疗后评估，不能混列。
- **Q4**：可切除人群的适用边界有来源，但额外加上的“HER2 3+需靶向治疗”不是该研究摘要本身的结论，应缩小论证范围。

### 其余失败稿也有内容问题

- **AFP结肠癌Q1**：病程同时记载“侵及浆膜层”及“T3”，没有记录“未穿透脏层腹膜”。不能为消除原文冲突补出这一事实。
- **AFP结肠癌Q4**：题干写CAPCET“证实优于”，自己的证据摘要却写“II期非比较研究”，题干前提与证据描述冲突。
- **髌骨转移Q5**：将随访CT明显钙化写成真实事件，但所给病例时间轴没有这项随访结果；应另有病例依据，或作为明确标记的延伸情境重写。
- **小肠癌Q3**：表格空栏不能自动证明该检测不应报告；Q5三个干扰项都依靠“单一指标即可”被排除，进阶性依然不足。

## 后续出题修订优先顺序

1. 修订轮先处理病例事实冲突、未知条件和时间点，再处理原句排版；不得为凑五题反推分级、分期和检查结果。
2. 引用采用绑定原文连续片段：保留原始转义/换行；两段不连续证据分开放入已允许的两元素数组。不能“自动相似匹配”掩盖拼接或不等号错误。
3. 对每项完整主张核对支持范围：确诊依据≠CR确认标准，群体预测≠个案组分归因，一般管理原则≠患者已满足具体停药阈值。
4. 证据确实不足时保留可核查草稿及缺口；五题完整和医学成立需同时满足。不得用删除校验或放宽失败状态来提高完成率。

这部分是待验证的出题修订清单，本轮没有宣称通过修改提示词解决这些医学内容问题。
