# MedSeek 中医文献增强问答系统

**项目角色：AI 工作流搭建 / 项目负责人**  
**项目时间：20XX.XX—20XX.XX**

## 项目背景

面向中医知识查询与临床参考场景，从 0 到 1 搭建基于中医原始文献知识库的智能问答工作流，并接入 MedSeek 应用，与产品客服模块共同提供专业问答和用户服务能力。

## 主要工作

- 独立完成中医问答工作流的需求分析、流程设计、节点搭建、提示词编写、变量传递、分支路由及端到端调试，实现从用户问题输入到最终答案输出的完整闭环。
- 设计通识回答、概念释义、鉴别诊断、方药查询、治法策略、医案经验、经典文献和针灸养生等 8 类中医意图，支持复合问题的多意图识别与并行处理。
- 搭建 RAG 检索链路，通过检索词改写、意图与文献类型映射、向量与关键词混合检索、Rerank、跨路去重及相关性排序，提高复杂中医问题的召回覆盖和证据相关性。
- 建立附件与病例上下文处理机制，支持 OCR 文本标准化、完整与精简上下文生成、历史病情摘要及用户问题拼接，为不同下游节点提供适配输入。
- 设计知识库约束型回答提示词，引入证据编号、来源信息、证据不足判断、抗提示注入和最终格式整理等机制，降低模型自由发挥、错误传播及无效输出风险。
- 使用 JavaScript 节点完成意图数组转换、文献类型筛选、检索结果拍平、基于 `dataId` 去重、按照 `rerankScore` 排序及输出数据清理。
- 将检索证据与自然语言答案分离保存，为前端展示、问题定位和后续审计提供结构化数据支持。
- 完成中医问答工作流与 MedSeek 应用的集成，并配合接入产品客服能力，实现专业医疗问题与产品咨询场景的分工处理。
