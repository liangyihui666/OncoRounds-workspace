# 精简版：表格换行匹配修复

基于“精简冻结版-五题-20260929”。本次仅修改01-出题子应用.json中的“首轮格式预检”和“最终程序检查与引用装配”两个节点的显示排版匹配函数。02与03逐字保持原样，作为配套快照附带。

如果目前已使用精简冻结版，只需在原有出题子应用中导入本包01文件，并核对导入后的知识库绑定。未修改线上应用，未调用模型API。

## 已确认的原因

本次附件包含完整内部诊断、五题第二轮草稿及引用来源，足够定位，无需重跑。模型实际生成五题。Q1至Q4通过了程序的字面回溯检查；Q5的C、D失败，导致整套公开题目返回0题。该程序通过与否不代表医学审核通过。

Q5绑定GB02，同一表格中的原文为：

```html
COOICANCER<br/>研究<br/>(NCT02881138)
COOICANCER<br/>研究<br/>(NCT03052634)[9]
```

模型引文为：

```text
COOICANCER研究(NCT02881138)
COOICANCER研究(NCT03052634)[9]
```

旧代码将br换成空格，只合并中文之间的空格，留下英文名称与中文、中文与括号之间的空格。这两处属于显示排版差异，却被报成原句不存在。

新代码记录HTML换行的来源；仅在该换行至少一侧为中文时，将其作为可消除的排版换行。普通英文单词之间的边界、数字边界、表格单元格/行边界、原文数值、否定和不等号仍保留。没有替换研究名称、补造引文或合并不同证据片段，没有增加病例或药名特例。

## 这套实际题目仍有的问题

- Q3：题干将“颅外病灶未进展”写在2019年4月，但提供的病例字段只在2021年9月明确记载颅外稳定。这次字面检查匹配到了引用的2019年句子，却不能证明题干新增的稳定条件。应核对原文；没有支持就修改题目，不能把后续状态提前使用。
- Q5：归类为“不良反应管理”，选项却主要考ORR、PFS和入组人群，未考查不良反应处理决策。它的C、D引文只有研究名称，缺少用于支持答案与解析的结果数字；A项引文只有入组人群，未直接提供其解析所用的PFS。研究名称匹配通过不能证明这些主张成立。此题需要重新设计或补全同一绑定证据内的有效依据，不能只修换行就认定合格。
- Q4：核心是药物组成记忆，现有患者背景并未实质改变作答；作为进阶临床决策题仍偏浅。此处是题目设计评价，不是新增医学结论。

上述问题记录为人工复核意见。本次未替用户改写医学答案，也未向工作流添加这些病例特例。最终仍保留publishable=false、medical_review_status=not_performed。该题组不应仅凭程序通过直接发布。
