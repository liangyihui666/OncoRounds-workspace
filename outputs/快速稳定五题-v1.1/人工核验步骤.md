## 一次核验一个可见动作

1. **节点：** FastGPT 工作流列表
   **字段/位置：** 导入应用
   **动作：** 只选择 `OncoRounds-快速稳定五题-v1.1-可直接导入.json`，导入为新测试应用。
   **预期结果：** 出现名为 `OncoRounds-快速稳定五题-v1.1-导入测试版` 的新应用，原生产应用仍存在且未被覆盖。
   **回传材料：** 工作流列表中生产版与导入测试版同时存在的截图。

2. **节点：** `irAE双锚点确定性拆分`
   **字段/位置：** 完整响应 → `query_a`、`query_b`、`needs_fallback`
   **动作：** 使用一个含两项已明确分级不良反应的脱敏输入运行节点调试。
   **预期结果：** 两个 query 只对应各自事件；肺炎/间质性肺病 query 保留感染鉴别边界；可确定性识别时 `needs_fallback=false`。
   **回传材料：** 完整节点输出。若 `needs_fallback=true`，再单独核验轻量回退只调用一次。

3. **节点：** `证据注册与压缩`
   **字段/位置：** 完整响应 → `compression_report` 与 `evidence_pool_json`
   **动作：** 使用一个脱敏病例运行节点调试。
   **预期结果：** 全局按 `docId+splitIndex` 去重；各路上限为 6/6/5/3/4/4；snippet 不超过 1000 字。
   **回传材料：** 完整 `compression_report` 和 `evidence_pool_json`。

4. **节点：** 原 `题目结构归一化`（改为纯机械结构硬检）
   **字段/位置：** 代码
   **动作：** 用含固定答案顺序的五题 JSON 调试两次。
   **预期结果：** 两次 `candidate_json_passthrough` 与字符串输入逐字一致，`structure_decision=PASS`；无选项重排、无字母分布逻辑。
   **回传材料：** 两次完整输出。

5. **节点：** 原 `题目结构归一化`（改为纯机械结构硬检）
   **字段/位置：** `cited_evidence_json`
   **动作：** 用五题草稿调试。
   **预期结果：** 只返回五题引用 locator 对应记录；临床研究补检记录可被选中；缺失 locator 时 `structure_decision=FAIL` 且错误一次列入 `structure_errors`。
   **回传材料：** 完整 `cited_evidence_json` 和 `structure_errors`。

6. **节点：** 循环节点
   **字段/位置：** 完整运行 JSON
   **动作：** 对同一脱敏病例执行一次端到端测试。
   **预期结果：** 最多两轮；只有最终独立 `decision=PASS` 才进入输出；成功恰好五题。
   **回传材料：** 两轮全部 `customOutputs`。
