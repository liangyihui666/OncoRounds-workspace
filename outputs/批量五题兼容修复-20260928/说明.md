# 批量工作流五题兼容修复

基于本次上传的8节点批量工作流修改。导入本目录“批量生成-五题兼容修复版.json”。维持最多10文件、10并发、0自动重试、原有应用绑定、节点位置和全部连线。

## 已确认的问题与修复

1. “三连”的文件输入 `fileUrlList` 选了引用模式却没有值。现绑定“并行开始 → 当前文件数组”，每个任务收到一个文件，不传整批文件。
2. 原汇总要求 `Questions.second_cancer_type` 必须存在，但最新公开展示输出只保留 `cancer_type`。用用户刚提供的真实五题结果回放，原代码返回 `INVALID_TAXONOMY_OR_COUNT`。现按公开契约校验；历史两级字段如存在仍检查类型及一致性，不伪造缺失分类。
3. 原代码允许1–4题且 generation_status=success 通过。现仅完整5题计入完成；1–4题返回错误占位。0题且 insufficient 保留病例页和缺口，计入 incomplete。
4. 新增“批量最终JSON → 批量完成情况 / 批量完成情况JSON”，显示完成、未完成、失败数量与需单独重试的上传序号。最终答复仍为原来的结果数组，不改变成功病例的 Questions/detail 内容。

数组引用采用编辑器的引用列表格式；没有修改文件校验逻辑、单病例出题逻辑或知识库。
