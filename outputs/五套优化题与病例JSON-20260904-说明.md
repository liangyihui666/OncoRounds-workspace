# 五套优化题与病例JSON

本批共10个独立JSON文件：5个病例，每例各有1份5题文件和1份病例内容文件，共25题。

## 文件对应

| 编号 | 病例 | 来源与处理 |
|---|---|---|
| 01 | 胃癌免疫相关胆管炎 | 导出上次优化的5题，整理完整病例摘要及病程 |
| 02 | GEJ腺癌pCR后复发 | 导出上次优化的5题，核实FDA引用的实际文件名与页码 |
| 03 | 食管鳞癌器官保存与TEN | 导出上次优化的5题；将缺乏来源支持的“轻度摄取”改为“仍有代谢摄取” |
| 04 | 乳腺小叶癌胃肠道与腹膜转移 | 本次重写5题，纠正原发病种及跨病种证据引用 |
| 05 | 炎性乳腺癌合并CMT | 本次重写5题，明确药物毒性、卵巢功能条件和动态受体状态 |

## 格式与使用

- 字段结构依照用户提供的两份ALK病例样例；题目选项为A/B/C/D对象，答案为字母，answer_text与对应选项完全一致。
- 每对文件case_id一致；病例内容保留样例的摘要、病程轴两个页签，不附加第三种页面结构。
- 保留原资料中的主题图片地址，未验证远端图片持续可访问性；未制造本地图片路径。
- 引用采用核对过的公开来源。没有可验证的知识库记录定位时，doc_id为空字符串、split_index为null，不伪造数据库记录或分块号。如果导入端强制要求数字分块号，应让展示层接受“无数据库定位”，不能随意填入别的记录编号。
- 所有题目按“当前教学复盘”处理：后来发表的证据不能被写成病例当时已经掌握的信息。
- generation_status=success只表示文件生成成功，不代表经过独立医学审核。正式教学或发布前仍需人工医学复核。

## 本次质量检查

- 10份文件均可直接解析为JSON，没有标题、代码围栏或多个对象拼接。
- 25题均完成答案与选项一致性、字段完整性和病例配对检查。
- 每套答案覆盖4个位置，同一位置最多2题；不靠删题满足答案分布。
- 同题四个选项的非空白、非标点字符长度接近；长度均衡是防线索措施，不等于已经实测题目难度和区分度。
- 两套新题原始病例存在的用药或日期冲突已在病例摘要“资料边界”及病程轴注明，没有擅自补齐。
- 原始附件和此前导出的文件均保留，未覆盖。

病例页展示完整病程；如用于逐时点考核，前端应控制未来病程展示，避免提前泄露后续检查结果。
