## 已确认的漏洞与修复

| 环节 | 已确认问题 | 修复 |
|---|---|---|
| 检索词生成 | 原代码先将换行压成空格，再按换行拆段。用户本次多行输入变成一条超长段落，被预算控制整体丢弃。分子、治疗、研究三路原查询只剩86/88/92字符，无实际方案及分子细节 | 先分行/分句，再逐段规范空白和选取完整源句；保留否定，不截断半句。提供保留/遗漏段落索引；查询上限480字符 |
| 治疗/研究检索 | B路偏向复评和后续，缺少初始治疗覆盖；研究查询只读取decision_points，容易没有原始药物方案 | 两路直接读取真实case_timeline与biomarkers，B路覆盖初始方案、治疗协调及调整；用原文实际方案检索，而不是把候选决策当医嘱 |
| 毒性事件识别 | 原模式表未覆盖本例意识障碍/血氨；未识别事件既未选入，也未总是触发回退 | 加入原文症状及血氨等事件识别；未知症状进入原有轻量回退；不据严重程度推断CTCAE分级 |
| 毒性类别 | 原代码用整个病例的一个治疗类别生成两路查询。本例复现为“化疗 皮肤毒性 G4”，漏掉西妥昔单抗 | 每条事件使用其自身涉事药物字段。两路优先覆盖不同治疗的严重事件，同药相关表现可保留于同路查询；未加入的分级不推测 |
| 研究补检 | 空datasets搜索节点仍处在补检链上；没有研究简称则停止补检，不能依赖它补足缺口 | 跳过并移除空知识库节点，从已有检索记录提取真实研究线索；没有简称时仍使用病例方案执行一次受限补检，不凭空编研究名 |
| 证据传递 | 首轮仅看到压缩到约1000字符的正文，第二轮才有完整正文 | 两轮均接收同一定位记录的完整返回正文；保留注册过滤、去重和元数据规则 |
| 出题合同 | 首轮、程序检查、最终输出、外层均接受1至5题为成功，五题只是提示词目标 | 提示词先安排五个不同决策；第二轮输入显式包含现有题数、缺位数、已有考点、未使用证据及格式错误；删除/去重后要求补位。恰好5题才输出完成状态 |
| 格式失败 | 格式错时整组被拦截，而最终结果缺原始第二轮正文，很难区分漏字段和截断 | 保留程序检查，提示词缩短并统一，清楚列出13字段和四行解析；两轮输出预算从8192提升至16000。失败诊断保留第二轮原文。该调整不意味着已证明之前是token截断 |
| 外层状态 | 零题时统称insufficient，且直接返回空病例页 | selection_report保留技术失败、格式失败、五题未完成状态和上游诊断；零题也生成病例页，病程轴独立展示 |
| 前处理 | 16个实际字段却要求“17个”；候选决策实际出现已知/未回报矛盾以及扩大停药范围 | 字段数纠正为16，14字段下游接口不变；在原字段规范内强化时序、中性决策和学习方向覆盖。接收代码仅添加输入一致性提示，不擅自重写病史 |

## 五题完成状态

- `OUTPUT_READY` + `output_ready=true`：第二轮恰好5题，并通过程序结构与引用定位检查。仍不等于医学审核通过。
- `INCOMPLETE_QUESTION_SET`：第二轮有1至4道程序有效草稿，尚未完成五题。正式questions为空，草稿保存在内部`diagnostics.partial_draft_questions`，不冒充五题完成。
- `FORMAT_ERROR`：程序检查失败。查看`program_check.errors`与`diagnostics.second_round_raw`；不补造evidence_id/keyPoint，也不回退首轮。
- `STOP_INSUFFICIENT`：第二轮明确返回零题，且通过零题结构检查。模型声明的缺口仍需对照实际记录，不直接等同于数据库无资料。

所有状态保留`publishable=false`、`medical_review_status=not_performed`。外层`medical_approval_confirmed=false`不变。内部诊断不进入学员端`output_data.Questions`或`detail`；在调试结果的`selection_report.source_groups`中查看。

少于5题改标未完成本身不会产生新题。提高可用题量依赖本次查询与证据传递修复，以及第二轮明确补位。若真实库返回不足，系统仍不能凭空生成5道可靠循证题。现有证据注册的来源身份限制和逐题适用性要求未放宽。

## 验证与限制

`离线检查报告.json`记录19项测试。包含真实前处理输入的旧/新查询对比、两路毒性匹配、未知分级/否定/多药物情境、补检路径、完整正文传递、引用去重、图连线和变量引用、无环/可达性、两轮与模型配置、1至4题未完成、格式失败保留原文，以及5题经子应用装配到外层的贯通。

五题贯通测试使用明确标记的合成题与合成证据，只证明接口和流程；没有把测试题当作本例临床题交付。

没有实际调用良医汇数据库或在线模型，不能宣称本例已经产出5道合格题，也不能确认此次运行原始检索是否返回了足够适用记录。此前用户结果中关于ICI资料和专项指南缺失的文字来自模型，尚无原始召回记录证明其准确。

已核对线上运行材料中的外层/子应用版本与本地交接基底。若用户曾另行调整线上节点而未导出，这些未提供的改动不在本次文件范围内。

模型仍为当前已配置模型，不切换到未核实的平台ID。完整正文和16000输出上限可能增加输入量及运行耗时；没有开展速度或模型质量对照测试。
