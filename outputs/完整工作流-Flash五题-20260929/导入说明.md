## 完整运行关系

批量上传HTML（最多10个） → 每个文件进入单例外层 → 读取/清洗正文 → 提取病例字段并检查 → 调用出题子应用 → 返回题目及执行状态 → 批量汇总。

出题子应用内部：病例包 → 指南/研究/不良反应检索及按需补检 → 证据汇总 → 第一轮Flash出题 → 程序检查 → 第二轮Flash修订 → 最终结构、来源和原句检查 → 输出成功五题或明确失败诊断。

两轮核心出题/修订模型保持Qwen3.8 Flash；其他清洗、提取及按需回退模型沿用原配置。成功必须完整5题；不以复制题、伪造事实或删除证据核对补足题量。公开解析仍为A/B/C/D四行。
