# 进阶出题建议与20分复核标准

这份建议针对现有五题病例组。继续保留原100分评价中的“进阶/20”，把该项展开为可复核的内容要求；不是模型自评、医学批准或自动发布阈值。若要比较改版前后，需用同一套细则重新评价两批题，不能直接把旧分数和新口径混比。

## 为什么目前难超过10分

此前《Qwen3.5 Plus试跑：同十例评分与比较》的进阶分为3、6、7分居多。报告里反复出现四种问题：

1. **病例只是背景。** 去掉病程，仍能选出“进一步检查”“结合结果”“多学科讨论”，不需要处理病例特有的矛盾。
2. **三个错误项太明显。** “仅凭”“不必”“一律”“忽略”等措辞把错误暴露出来，选最长、最全面的选项即可。
3. **一套题重复一个原则。** 受体要复测、治疗看受体、不要忽略受体，表面不同，实际一次判断就能解三题。
4. **证据不足时退回基础题。** 脑膜转移、梗阻、局部与全身控制等核心问题没有召回可用依据，最后变成普通分期、检测和流程题。

换模型或加上“高年资、进阶、复杂”标签，不能直接解决这些问题。先确保检索正文支持有条件的取舍，再形成题目。

## 出题前先找什么

先看全文中是否存在可用于区分选项的条件：适用人群、治疗阶段、必要前提、时机、治疗目的、既往治疗、耐受性、复评状态或研究外推边界。只有一句宽泛原则的记录，通常无法独自支撑四个具有竞争力的选项。

然后检查病例里哪些条件在这个时点已经明确。通常选2至3个真正影响行动的条件；若考察的是一个关键研究适用边界或前后状态变化，也可以达到进阶，不必机械堆满三个因素。患者年龄、癌种、日期写了很多，不代表存在多个有效推理条件。

最后再选题型和写选项。反过来先写一个熟悉的通用答案，再寻找相似引文，容易造成“真引用、错应用”。

## 一题应写清的五件事

| 内容 | 编辑应能直接回答 |
|---|---|
| 决策 | 患者在这个时点到底要解决什么问题？ |
| 关键病例条件 | 哪些已知事实改变了方案选择？原句在哪里？ |
| 正确项依据 | 哪段绑定正文支持该项的全部措施，而不只支持其中一个动作？ |
| 最接近的竞争项 | 为什么临床上容易选它？本题凭哪条明确条件排除？ |
| 适用边界 | 条件如何变化时，该竞争项可能成立？原文是否真的支持这个变化？ |

这次工作流新增的 `verification` 就记录上述核对材料的一部分：四项引文、关键病例原句、最接近的竞争项及短判别依据。**填写齐全不能自动证明题目进阶。** 原句匹配程序只能确认文字存在，不能裁定临床推论。

## 从基础问题升级的方向

下表是选题方向，不是现成医学答案。只有返回证据明确支持这些取舍时才能采用。

| 常见低分问题 | 可以寻找的进阶方向 | 不应怎么加难 |
|---|---|---|
| 病灶是否需要检查/活检？ | 检查已经完成或结果不一致后，哪一项尚未满足的条件真正影响下一步决策？ | 为制造冲突补造一个病例没有的检查结果 |
| 是否应按受体或分子结果治疗？ | 检测时点、样本及既往治疗背景不同时，证据支持哪一种应用范围？ | 将“某指标未知”写成阴性，或把检测清单写成人人必做 |
| 局部治疗能否替代全身治疗？ | 在局部与其他部位控制不一致、既往治疗或可及性受限时，比较同一证据支持的协调策略 | 连续三题都考“局部不能替代全身” |
| 研究ORR/PFS是多少？ | 哪个人群或设计条件限制其结论用于本例？哪个选项扩大了研究可证明的范围？ | 生造研究对照、亚组结果或把非随机数值差异当优效 |
| 毒性发生后是否处理？ | 责任药、明确等级、首次/再次事件、恢复状态已知时，比较对应管理阶段 | 把未知等级补成3级，或用同名毒性跨药物类别套规则 |
| 是否定期复评？ | 对照前后病程信息和来源适用条件，区分继续观察、补充核实、调整计划的证据边界 | 将另一阶段/部位的频率改写成本例必须执行 |

## 四个维度，各0至5分

建议每题按下表各打0至5分，五题的总分取平均，得到整套“进阶/20”。中间分数须注明具体理由，不按题干长度或名词数量打分。

| 维度 | 0–1分 | 2–3分 | 4–5分 |
|---|---|---|---|
| 决策任务 | 原文数字/分期记忆、常规流程或泛泛原则 | 有明确情境，但基本可直接套条款 | 对应病例真实难点，需要在证据允许的行动之间作有条件的取舍 |
| 有效条件整合 | 病例信息是装饰，删去也不影响作答 | 至少一个关键条件确实改变答案 | 多个条件有实际相互约束，或一个复杂适用边界/状态变化决定行动；每个关键条件可追溯 |
| 竞争方案质量 | 错误项靠极端措辞即可排除，或正确项明显最长 | 至少一个干扰项合理，但区分较直接 | 最接近方案有明确适用条件，题干足以唯一排除；选项层次、范围和具体程度相近 |
| 动态管理或证据迁移 | 只复述患者后来接受了什么 | 能解释某一条件下为何采用条款 | 能在当前时点判断前后变化或研究适用边界，保留不确定性、不偷用未来信息、不超出证据 |

重复考点应反映在对应题的“决策任务”和“动态管理或证据迁移”评分中，不能因为换了措辞就反复给高分。病例核心缺失同时仍应在原100分体系的“完整与覆盖”项扣分，不把这部分重复混入新造的自动门槛。

含虚构患者事实、错误引用、多解或缺乏排除依据的题，先标记“待重写”，不能把表面复杂度当成合格进阶表现；整套进阶达标结论等修复后再给。这里不设模型自报分数，也不让高进阶分抵销医学错误。

**建议编辑目标：平均14/20以上，且至少3题直接考察有证据的条件取舍或动态/适用边界。** 这是本轮的设计目标，尚未由新一批模型输出验证，不是当前质量成绩。

## 第二轮不要只润色

按顺序检查：引文是否存在 → 引文上下文是否支持题意 → 病例条件是否属于此时点 → 四项是否唯一正确 → 最接近竞争项是否确有竞争力 → 是否与其他题重复。

若仅有文字错误，局部修改。若决策、适用范围或正确项变了，应连同题干、四项、解析、知识点、摘要和核对材料一起重写。已经合格的选项顺序保留。

不要为了提高“进阶分”新增患者禁忌、毒性等级、实验室数值或未返回研究结论。没有对应证据就披露缺口，不能把基础题换个标题后算进阶题。

## 下一批如何判断是否有效

逐题记录四维分数、关键条件、最接近的竞争项，以及原句匹配通过但语义仍有问题的情况。同时比较五题完成率、核心问题覆盖、重复考点和医学错误；不能只看20分上涨。

加强原句核对后，旧稿会因为缺少核对材料被要求修订，失败率也可能暂时上升。只有新运行中同时看到可追溯性、内容质量和交付完整性改善，才能认为工作流实际变好。
