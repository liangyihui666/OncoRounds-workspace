# 三连：单次出题与终稿优化测试版

底稿：用户提供的「三连 (9).json」。本次只修改三连，不修改「题目生成 (9).json」或线上应用。

## 新流程

正文清洗 → 病例提取 → 格式修复 → 病例变量 → **调用一次题目生成** → 单组候选检查 → 终稿优化 → JSON输出。

- 删除题目生成#2、题目生成#3及其连线和输入引用。保留的调用沿用原应用绑定和版本设置；其内部检索、独立医审及修订不变。
- 单次调用接收完整教学重点，取消原来的A组专属侧重。目标5题，不足时允许输出1至4题。
- 原「15题候选池拼接」改为「单组候选检查与终稿输入」；原「千问15选5」改为「单组题目终稿优化」。
- 终稿模型只返回原候选ID和可选文字补丁，允许等义整理题干、解析、知识点。选项内容、正确答案、阶段、时间和整个guidelineRef由代码锁定；保留原有答案位置分散逻辑，答案字母始终与答案文本对应。
- 数字、英文术语、部分否定/不确定性及治疗动作词变化、非法字段和过度删减会被代码拒绝；失败字段保留原文。此类检查不能证明所有中文改写都医学等义，发生文字修改时，诊断报告明确标记上游医审仅适用于修改前的原题，不将其称为修改后的医学PASS。
- 完全重复题合并，恢复原题顺序；错误ID、无法解析或终稿模型报错时回退已有原题，不凑数。零题/子流程报错时直接输出不足原因，跳过终稿模型。
- 终稿输入移除完整病例、证据池和重复结构诊断，仅保留所需题目及绑定的逐题审核信息；后台候选池及原始记录仍保留。示例输入从8310字符降为4187字符，不等同于线上耗时减少相同比例。
- 继续使用原模型，终稿关闭思考、视觉及文件提取，JSON格式输出，上限4096 token。

## 输出及既有约定

保持一个 `{Questions, detail}` JSON。胃癌、肺癌、直肠癌、乳腺癌、食管癌、胰腺癌直接作为展示癌种，其他仍沿用项目映射；second_cancer_type仅用于内部分类，不出现在Questions或detail。病例图片image_items固定为空，封面src为空，避免把患者检查图当主题封面。

格式修复节点保留evidence_notes，不再删除原有临床不确定性说明。病程轴没有绝对日期时保留原文中的「初诊时」「术后3个月」等阶段。其余详情继续采用本次导出已有的自动装配方式，并非此前44例逐例人工整理文案。

## 验证范围

12项离线检查通过，包括全部代码编译、节点引用、单次调用、零题旁路、错误回退、1至5题、重复题、文字补丁保护、原始指南完整性、相对时间，以及现有44例220题的引用保留回归。未调用真实模型或数据库，未导入线上平台；这些检查不等同于新生成内容的医学审核。
