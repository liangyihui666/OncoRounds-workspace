# OncoRounds

肿瘤医生大查房移动端 Demo。当前版本：v1.2 癌种筛选与专属查房交互演示（2026-09-08）。

## 在线体验

GitHub Pages：<https://liangyihui666.github.io/OncoRounds/>

## 使用说明

- 推荐使用手机浏览器或浏览器移动设备模式访问。
- 当前为医学教学灰度 Demo，病例资料均为已获授权的内置脱敏内容。
- 页面中的题目与解析仅用于医学教学，不替代临床诊疗意见。

## 部署

推送到 `main` 分支后，`.github/workflows/pages.yml` 会自动发布根目录中的静态 H5。

## 本次更新

- 病例广场支持肺癌、胃癌、乳腺癌、食管癌、GEJ腺癌筛选，共九例、每例五题。
- 保留卡片滑动、双标签详情、答题回顾、总结及同癌种下一病例。
- 专属查房提供文件选择和模拟生成、失败重试、退出续答与完成记录。文件不会上传或解析；生成结果来自用户选定的内置演示病例。
- 专属记录与答题进度仅在当前页面内存保存，刷新清空。
- 新增病例通过独立演示适配层接入，缺失知识库定位不补造，正式题库发布门禁保持不变。

## 源码与验证

完整源码位于 `02-完整源码/`，根目录的 `index.html` 与 `assets/` 是同一次生产构建的演示产物。

```sh
cd 02-完整源码
pnpm install --frozen-lockfile
pnpm exec vitest run
pnpm build
```

构建完成后，将 `dist/index.html` 与 `dist/assets/` 同步到仓库根目录。不要直接修改构建产物。

本版本交付前通过 51 项测试及生产构建，并检查了五种视口和独立解压后的本机 HTTP 演示。自动浏览器不支持 `file://`，未声称完成双击打开验证。详见 [修改与验收记录](修改与验收记录.md)。
